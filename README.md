# WEGA Urban EVD 3GR — Flagship Scrollytelling Landing Page

Apple-level scrollytelling product experience for the **WEGA Urban EVD 3GR** three-group commercial espresso machine, driven by a 120-frame 60fps HTML5 Canvas sequence and synchronized Framer Motion storytelling beats.

## Features

- **60fps HTML5 Canvas Sequence:** Two-wave prioritized preloading across 120 frames with damped lerp smoothing and HiDPI scaling.
- **Seamless Obsidian Void Blending:** Exact `#070707` studio match with canvas-level edge feathering and radial vignette.
- **5-Beat Synchronized Scrollytelling:** Hero, Architecture & Craft, Signature Innovation, Sensory Extraction, and Resolution CTA.
- **Apple-Inspired Glassmorphic Navbar:** Transparent at scroll top, transitioning to blurred obsidian glass with smooth chapter jumping and TR/EN locale switcher.
- **Specs Matrix & Experience Modal:** Editorial technical specifications section and private showroom demo inquiry modal.

## Tech Stack

- Next.js 15 (App Router)
- React 19 & TypeScript
- Tailwind CSS v4
- Framer Motion
- Lucide Icons

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
